# Comms Check

An unofficial dashboard for watching and running a Riedel Bolero standalone intercom. It is not made or supported by Riedel Communications, and it can change the settings of a live system. Use it with care.

## Download

Get the latest build from the [Releases page](https://github.com/Deanbau/CommsCheck-releases/releases/latest).

- `CommsCheck-<version>-mac-arm64.dmg` is for Apple silicon Macs. It does not run on Intel Macs.
- `SHA256SUMS.txt` lets you check the download is the file that was built.

## Install on a Mac

The app is not code-signed, so macOS warns the first time.

1. Open the .dmg and drag Comms Check to Applications.
2. Right-click the app and choose Open.
3. If macOS says the app is damaged, run: `xattr -dr com.apple.quarantine "/Applications/Comms Check.app"`

This repo only holds downloads. The source is private.
