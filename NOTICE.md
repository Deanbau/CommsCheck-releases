## How it works with the equipment

Comms Check talks to a Bolero system through the same network interface that the system's own web page uses. Riedel does not document or support that interface. It was worked out by watching how the system's own page behaves, so that this tool can work with equipment its user already owns and operates. It can change with any firmware update, which can stop parts of Comms Check working or make them behave differently.

## Use at your own risk

Comms Check can change the settings of a live intercom system: keys, audio settings, profiles, partylines, menu access, registration and the admin password in use. Try changes on a spare pack first. Save a setup snapshot before you start. Do not rely on it as the only way of watching a system during a live show.
